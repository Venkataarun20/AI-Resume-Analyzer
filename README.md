# AI Resume Analyzer

An AI-powered Resume Analyzer built using Python and Streamlit.

## Features

- Upload PDF Resume
- Extract Resume Text
- Detect Technical Skills
- Find Missing Skills
- ATS Score Calculation

## Technologies Used

- Python
- Streamlit
- PyPDF2

## Run Locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
